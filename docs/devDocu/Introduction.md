# Introducción a Knight - Shell

Mientras muchas otras Shells se escriben en C con ordenes y miles de archivos complicados de entender, Knight Shell presenta su código de manera limpia y bien explicada.

Siempre se busca en esta que el usuario pueda desarrollar, ayudar y entender su versión de Knight Shell al maximo.

##  Elige tu Rama de Contribución

Siendo así, encontramos varias divisiones y ramas en las que puedes decidir separarte para encontrar tu camino de desarrollo en el proyecto:

> [Ramas de Desarrollo](./Select-Your-Team.md)

Aunque en este archivo se presentan y desarrollan explicitamente todas las ramas posibles de contribucion del proyecto, aquí presentamos los nombres para que puedas 
hacerte una idea.

> - Documentador
> - Analista
> - Fixer
> - Developer
> - Maintener

## Conocimientos Previos

Para poder crear cambios y contribuir de una manera completa se recomienda encarecidamente el conocimiento en algunas areas y tecnologias de desarrollo, siendo algunas de estas:

1. C Programming Language
2. Bash Scripting
3. Creación de Makefiles completos
4. Tener experiencia en desarrollo o empezar por el camino recomendado en el [CONTRIBUTING FILE](../CONTRIBUTING.md)

En cualquiera de los explicados casos siempre se tienen que buscar cambios que supongan una mejora clara para la fluidez o experiencia de usuario.

Cualquier cambio es analizado y tomado milimetricamente enserio para poder brindar una experiencia tan completa que el usuario no experimente problemas.
