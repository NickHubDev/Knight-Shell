# Knight Shell (KSH)

## What is Knight Shell?

**Knight Shell (KSH)** is a command-line shell written in C, designed to combine two essential aspects of the command-line experience: **speed and usability, together with customization and visual appeal.**

The goal of Knight Shell is to provide a lightweight and efficient shell environment without sacrificing the ability to personalize the way users interact with their terminal.

With the release of [**version 0.9.0**](../../release/v0.9.0), Knight Shell introduces a new customization system that allows users to create their own prompts and personalize their appearance, providing a more comfortable, recognizable, and visually appealing command-line experience.

## Prerequisites

Whether you want to customize Knight Shell for personal use or contribute directly to its development, the following knowledge will be useful:

1. **C Programming (Intermediate)** — A reasonable understanding of C, including functions, pointers, structures, and memory management.
   
2. **Bash Scripting (Basic)** — Familiarity with shell scripting concepts and command-line environments.
   
3. **Git and GitHub (Basic)** — Basic knowledge of version control, repositories, branches, and pull requests.
   

These prerequisites are intended to help contributors navigate the codebase and understand the project's development workflow.
