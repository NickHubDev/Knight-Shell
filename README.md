## Installation

#### How To Install?

To install **KnightSH**, first clone the repository:

```bash
git clone https://github.com/NickHubDev/Knight-Shell.git
```

After cloning the repository, run the `install.sh` script to start the installation process:

```bash
./install.sh
```

During execution, you will see the following prompt:

```bash
Are You Sure You Want to Proof this Material? [y/n]
```

Press **"y"** or **Enter** to proceed. Once finished, you can launch the shell by typing:

```bash
knight
```

## Features

#### Efficiency
Built entirely in C, this shell is designed to be highly efficient, lightweight, and fast.

#### Simplicity
We are working to bring new customization features to the public, including the ability to configure the shell using `.kss` files. These files are designed to be simple, easy to understand, and straightforward to write.
